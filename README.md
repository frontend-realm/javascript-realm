# JavaScript Realm

A structured, topic-by-topic log of my JavaScript learning journey — organized as **Phases → Components → Files**, so the whole repo grows the same way no matter how many topics get added.

## Structure

| Level | Folder/File | Meaning |
|---|---|---|
| 📦 Module | `src/phase X - <name>` | A phase — a broad stage of learning (e.g. JS Core, Advanced JS, Async JS) |
| 🧩 Component | `<theme name>/` | A week/theme within a phase — a group of related topics |
| 📄 File | `<topic>.js` | A single topic, exercise, or episode's notes/code within that theme |

```
src/
└── phase 1 - JS CORE (Namaste JS)/          # Module: Phase 1
    └── Execution Model & Scope/             # Component: theme for this phase
        └── ep-1&ep-2.js                     # File: How JS works — execution context, call stack (Namaste EP 1–2)
        └── ep-3&ep-4.js                     # File: Hoisting; how functions work & variable environments (EP 3–4)
        └── ep-5&ep-6.js                     # File: Shortest JS program, window & this; undefined vs not defined (EP 5–6)
        └── ep-7.js                          # File: Scope chain & lexical environment (EP 7)
        └── ep-8&ep-9.js                     # File: let / const, TDZ, block scope & shadowing (EP 8–9)
        └── ep1-to-ep9-OP-ques.js            # File: Output Problems - 1 - (Ep1 → Ep9)
    └── Closures & Functions/                # Component: theme for this phase
        └── ep-10.js                         # File: Closures (EP 10)
        └── ep-11.js                         # File: setTimeout + closures — the classic var-in-loop problem (EP 11)
        └── ep-12.js                         # File: Famous closure interview questions (EP 12)
        └── ep-13.js                         # File: First-class functions; function statement vs expression; anonymous functions (EP 13)
```
