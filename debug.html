How to debug
1. Set the file path in the <script src> tag in debug.html.
2. Open DevTools with F12 or ⌘ ⌥ I.
3. Find the file under Sources and click a line number to add a breakpoint, or put debugger; in the file.
4. Reload the page to re-run it.
